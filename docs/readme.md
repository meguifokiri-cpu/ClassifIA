# ClassifIA — Classification d’Images

## 📌 Description

Application de classification d’images (plantes et animaux) utilisant l’intelligence artificielle.

## 🎯 Objectifs

* Collecter et préparer les données (E1)
* Déployer un modèle IA (E3)
* Créer une application complète (E4)

## 🧱 Stack technique

* Python
* FastAPI
* TensorFlow / PyTorch
* Streamlit

## 📁 Structure du projet

* data/ : données brutes et traitées
* model/ : modèle IA
* api/ : backend FastAPI
* app/ : interface utilisateur

## 🚀 Installation

```bash
pip install -r requirements.txt
```
